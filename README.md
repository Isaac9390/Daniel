
# Student Registration Form

## Project Description
This project is a simple Student Registration Form
developed using HTML and CSS.

## Technologies Used
- HTML
- CSS

## Features
- Student Name
- Email Address
- Phone Number
- Course Selection
- Address
- Register Button

## How to Run
1. Create a project folder.
2. Create index.html.
3. Create style.css.
4. Create README.md.
5. Open index.html in your browser.
